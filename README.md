# 周末城市探索指南

> 帮大学生用 30 秒定下周末去哪，并一键约到同行的人。

「周末城市探索指南」是一款本地周末探索工具：用**智能决策 + 实时组队执行**，帮你解决"不知道去哪、约不到人、计划易崩"。我们不做又一个内容平台，而是帮你看少一点、走多一点。

---

## 如何开始

🌐 **在线体验**：[https://gl7lmt.csb.app](https://gl7lmt.csb.app)

打开后请注意：

- **加载**：首次打开可能需要 3–5 秒加载，请稍候。
- **定位授权**：浏览器会请求地理位置权限。**允许**可体验"就近推荐"；**拒绝**会自动回退到默认城市（深圳），功能完全可用。
- **数据说明**：当前景点、餐厅、天气为**演示数据**，用于展示产品逻辑；后续会接入真实数据。
- **本地保存**：你的行程、打卡、组队等数据保存在**当前浏览器本地**，换浏览器或清空缓存会重置。
- **设备**：推荐使用手机或桌面浏览器（Chrome / Safari）打开，已做移动端适配。
- **已开通城市**：深圳 / 上海 / 北京 / 成都；广州 / 杭州 / 武汉 / 西安 / 重庆 为"筹备中"（可提交开通申请）。

## 主要功能与使用方式

### 1️⃣ 一句话对话式决策（探索推荐）
- **怎么用**：在顶部输入框直接用自然语言说一句，例如「两个人 人均一百 想看展 下午去」——**兴趣 / 预算 / 同行 / 场地全部可选**，不填也能用。
- **做了什么**：自动理解你的意图，并用一句人话**告诉你"我理解成…"**；按 偏好 × 天气 × 预算 × 人数 四维实时排序，每个结果给出 **匹配度分数 + 一句推荐理由**。
- **懒人模式**：不想选时点「帮我挑 3 个」，直接给 3 个最匹配的结果。

### 2️⃣ 一键排成「完整的一天」
- **怎么用**：看中想去的活动后，点「直接排成一整天」，一键生成 **分天 + 分时段** 的行程。
- **做了什么**：自动分 上午 / 下午 / 傍晚 / 夜间 四时段排布、就近安排**吃饭**、计算站间**通勤时间**、雨天自动把室内项前移并标注"备伞"。
- **预算可控**：单餐费用上限 = 预算的 40%；超预算时标红提示并给「按预算精简」按钮（至少保留 3 个去处）。

### 3️⃣ 组队出发
- **怎么用**：在活动或"没人组队的去处"上一键发起 / 加入队伍，支持满员、退出。
- **做了什么**：把"推荐活动 → 为该活动即时组队 → 一起执行"串成闭环；集合点可一键唤起地图导航（调用地图，不自建）。

### 4️⃣ 我的周末（轻量记录）
- **怎么用**：把想去 / 去过的活动加入行程单、打卡记录、发布轻量攻略。
- **定位**：刻意**轻量**，不与核心功能抢视线——帮你留个念想，但不堆功能。

## 产品理念

- **重"帮你做决定"，轻"内容堆砌"**：市面上的内容已经够多了，我们专注减少你的决策摩擦。
- **不做内容社区**：不抢小红书 / 抖音的饭碗，不做 UGC 流量运营。
- **不碰资金与导航基建**：不做 OTA / 支付，地图用一键唤起，不自建。
- **关于"信息分散"**：我们不把它当卖点，而是默默做好数据底座——先把每座城市精选好，再逐步接入更多真实来源。

## 关于数据与技术

- **演示数据**：当前为采样数据，用于展示产品逻辑，非真实商业数据。
- **隐私**：你的数据只存在本地浏览器，我们不收集、不上传。
- **技术**：纯前端、零框架、无需安装；数据驱动，新增城市只需加一条数据。
